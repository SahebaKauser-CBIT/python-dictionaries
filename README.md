
# Python Dictionaries

## Overview
This project demonstrates how to create, access, update, delete,
and iterate through Python dictionaries.

## Programs
- `src/dictionary_basics.py`: Demonstrates dictionary operations.
- `src/student_record.py`: Student Record Management System.
- `docs/dictionary_notes.md`: Notes about Python dictionaries.

## Concepts Covered
- Dictionary creation and access
- Adding and updating key-value pairs
- Removing dictionary entries
- Iterating through dictionaries
- Functions and structured data

## How to Run
```bash
python src/dictionary_basics.py
python src/student_record.py
```
